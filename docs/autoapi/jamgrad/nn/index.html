Parameters:

  • out_features (int) – Size of output features

jamgrad.nn.relu(x)¶

Rectified Linear Unit activation function.

Applies the function element-wise: f(x) = max(0, x)

Parameters:

x (Tensor) – Input tensor

Returns:

Output tensor with ReLU applied

Return type:

Tensor

Examples

>>> x = Tensor([-1, 0, 1, 2])
>>> y = relu(x)  # [0, 0, 1, 2]
jamgrad.nn.softmax(x)¶

Softmax activation function.

Applies softmax function along the last dimension: softmax(x_i) = exp(x_i) / sum(exp(x_j)) for all j

Parameters:

x (Tensor) – Input tensor

Returns:

Output tensor with softmax applied

Return type:

Tensor

Examples

>>> x = Tensor([[1, 2, 3]])
>>> y = softmax(x)  # Probabilities that sum to 1
